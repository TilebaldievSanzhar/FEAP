# Как реально подаётся ДТ в Кыргызстане: карта систем и фактчек

**Дата:** 2026-07-04
**Статус:** research / фактчек. Дополняет и корректирует `docs/Таможенное оформление товаров в Кыргызстане.md`.
**Метод:** открытые источники (сайты ГТС КР, ЕЭК, ГТК РБ, Tazabek, 24.kg, trade.kg, cdb.kz), июль 2026.

Каждое утверждение помечено:
- ✅ **подтверждено** — есть открытый источник;
- ⚠️ **частично** — источник косвенный или устаревший;
- ❓ **предположение** — требует верификации (см. §7 «План верификации»).

---

## 1. Главный вывод для продукта

**В Кыргызстане нет публичного API для подачи ДТ, и подача — не наша задача.**
Декларации подаются в **ЕАИС ГТС** через платный веб-инструмент **АРМ «Брокер»**
(ГП «Таможенная инфраструктура» при ГТС). Значит, реалистичный продукт — это
**подготовка идеального проекта ДТ + пакета документов** с экспортом в форматы,
которые декларант переносит в АРМ «Брокер» за минуты (XLSX / печатная форма /
копи-режим), и со ставкой на **единый XML-формат ЕАЭС (Решение Коллегии ЕЭК № 75,
структура R.055)** как на будущий канал переноса: Казахстан уже официально
принимает загрузку таких XML в ИС KEDEN — прецедент для всего союза.

## 2. Карта систем таможенного контура КР

| Система | URL | Что это | Статус факта |
|---|---|---|---|
| **ЕАИС ГТС** | (внутренняя) | Единая автоматизированная информационная система таможенных органов КР. Все ДТ регистрируются в ней. Модули: э-Декларация, э-Платежи, управление рисками, «Авторегистрация», «Автовыпуск» (план — до 31.12.2025 по Концепции развития ГТС 2022–2025, ПКМ № 202 от 08.04.2022) | ✅ |
| **АРМ «Брокер»** | доступ через договор с ГП «Таможенная инфраструктура» | Веб-АРМ для заполнения и подачи ДТ в ЕАИС. **Платный: 150 сом за основной лист ДТ, 100 сом за каждый добавочный лист**, отчётный период — месяц. Без договора с ГП таможенный представитель не может пользоваться. Платная эксплуатация — с 01.03.2021; в апреле 2021 на доработку выделяли 9,5 млн сомов | ✅ (тарифы 2021 г.; актуальные — проверить) |
| **eais.customs.kg** | https://eais.customs.kg | Информационный портал ГТС: классификаторы, курсы валют, информация об АРМ «Брокер». Не транзакционный | ✅ |
| **pi.customs.gov.kg** | https://pi.customs.gov.kg | Портал ГТС, на котором сейчас размещён вход в систему **«Санарип Тамга»** (есть dev-инстанс devpi2.customs.gov.kg «SANARIP Tamga: Вход»). Санарип Тамга — платформа электронного взаимодействия государственных контролирующих органов на границе: обмен предварительной информацией от УВЭД, решения о формах контроля до прибытия груза, принцип «единой остановки». С 2024–2025 масштабируется на КПП («Кайрагач», «Кызыл-Бел», «Кен-Сай» и др.) | ✅ что портал = Санарип Тамга; ❓ подаются ли через него сами ДТ (по открытым данным — это предварительное информирование и риски, а не декларирование; ДТ идут через АРМ «Брокер» → ЕАИС) |
| **exch.customs.gov.kg** | https://exch.customs.gov.kg | «Портал информационного обмена ГТС КР» — закрытый (логин/пароль). Публичной документации по API нет | ✅ существует; ❓ назначение (вероятно, обмен с информационными операторами / предварительное информирование) |
| **ИСЕО / TULPAR** | https://swis2.trade.kg | Информационная система «единого окна» во внешней торговле. Оператор — ГП «Центр "единого окна"» (trade.kg), сейчас **при ГТС при Минфине КР** (ранее при Минэкономики). Модернизированная версия запущена 01.02.2023. Выдача разрешительных документов + **публичные реестры**: декларации/сертификаты соответствия ТР КР и ТР ТС/ЕАЭС, СГР, лицензии (алкоголь). Поиск по номеру, статусу, ИНН, коду ТН ВЭД | ✅ |
| **Тундук** | catalog.tunduk.kg | ГСМЭВ (аналог X-Road). ГТС и её ЕАИС зарегистрированы как участники/подсистемы. Потенциальный канал интеграций с гос. данными (ИНН → реквизиты компании) | ✅ существует; ❓ доступ частным компаниям к нужным сервисам |
| **hscode.customs.gov.kg** | https://hscode.customs.gov.kg | Государственный ML-классификатор ТН ВЭД (model_v5_2v). Бесплатный, быстрый (~1.5 c), но слабый на сложных кейсах: Code-10 accuracy 48% vs наши 77% (см. `docs/benchmark_v27_vs_hscode_kg.md`) | ✅ (наш бенчмарк) |

**Роли, коротко:** ТУЛПАР — *до* декларирования (разрешительные документы → номера в графу 44); АРМ «Брокер» → ЕАИС — *само* декларирование; Санарип Тамга — граница/предварительное информирование; exch — межсистемный обмен.

## 3. Нормативная база формы и формата ДТ

| Что | Документ | Статус |
|---|---|---|
| Форма ДТ и порядок заполнения 54 граф | **Решение КТС № 257 от 20.05.2010** (с изменениями; очередные правки порядка заполнения вступили в силу **01.04.2025**, в т.ч. Решение Коллегии ЕЭК № 26, март 2024) | ✅ |
| Классификаторы для заполнения ДТ (виды процедур, документов, льгот, характер сделки, виды транспорта и т.д.) | **Решение КТС № 378 от 20.09.2010** (регулярно обновляется) | ✅ (номер решения — общеизвестный; конкретную редакцию сверить при парсинге) |
| **Электронная структура и формат ДТ (XML)** | **Решение Коллегии ЕЭК № 75 от 30.05.2023** «О структуре и формате декларации на товары и корректировки декларации на товары», идентификатор структуры **R.055**, версия 1.0.0 применяется **с 01.04.2024**. Правки: № 146 (27.09.2023), № 26 (26.03.2024), № 63 (07.07.2025), № 90 (07.10.2025). ЕЭК ведёт публичный реестр «Ведение структур и форматов таможенных документов» | ✅ |
| Транзитная декларация: структура/формат | Решение Коллегии ЕЭК № 74 от 30.05.2023; новая форма ТД — Решение № 73 от 30.05.2023 | ✅ |
| ДТ электронной торговли | Решение Коллегии ЕЭК № 144 от 17.12.2024 | ✅ |

**Следствие:** «шаблон ДТ» для генерации — это не выдумка и не наш произвол.
Целевые артефакты жёстко заданы: (а) печатная форма по Решению 257,
(б) XML по структуре R.055 из Решения 75. Оба — юридически едины для всех
5 стран ЕАЭС. Это же — готовая спецификация валидации (обязательность граф,
форматы значений, справочники из Решения 378).

**Прецедент Казахстана (важно):** при переходе с АСТАНА-1 на ИС **KEDEN**
(переход на декларирование в KEDEN ~ апрель 2026) КГД РК официально принимает
**загрузку ДТ файлом .xml по Решению № 75** и **.xls через модуль «Спецификация»**.
То есть в соседней стране ЕАЭС наш экспортный XML уже был бы рабочим каналом
подачи без всякого API. Вероятность аналогичной функции в ЕАИС КР высокая
(нормативно обязаны поддерживать те же структуры). ✅

## 4. Как выглядит реальный путь импортной поставки (сводный, подтверждённый)

```
0. Разрешительные документы (до прибытия груза)
   ИСЕО TULPAR (swis2.trade.kg): заявка → сертификат/декларация соответствия/СГР
   → запись в публичном реестре со статусом «Действует»            [✅]

1. Предварительное информирование (граница)
   Санарип Тамга (pi.customs.gov.kg): ПИ от перевозчика/УВЭД,
   консолидация рисков ГКО, «единая остановка» на КПП               [✅]

2. Прибытие, транзит, СВХ/ЗТК                                        [✅]

3. Заполнение и подача ДТ
   АРМ «Брокер» (веб, договор с ГП «Таможенная инфраструктура»,
   150/100 сом за лист) → ЕАИС ГТС. ЭЦП обязательна                  [✅]
   Ручной ввод 54 граф + прикрепление документов                     [⚠️ детали UI/импорта — верифицировать]

4. Регистрация → СУР (риски) → запрос документов/досмотр/КТС
   → уплата (графа B, единый лицевой счёт) → выпуск                  [✅ в общих чертах]
   Модули «Авторегистрация»/«Автовыпуск» — в Концепции до конца 2025 [✅ план; ❓ фактический статус]

5. Пост-таможенный контроль (до 3 лет), корректировки (КДТ)          [✅ по праву ЕАЭС]
```

Время ручного заполнения одной ДТ — 30–60 минут (оценка из v1-документа,
консистентна с опытом РФ/КЗ). ❓ — уточнить у практиков КР.

## 6. Возможности интеграции — трезвая оценка

| Канал | Сегодня | Перспектива |
|---|---|---|
| API подачи ДТ в ЕАИС | ❌ нет публичного | Следить за ЛК УВЭД/ЕАИС; статус «информационного оператора» в КР пока не существует как институт ❓ |
| Импорт файла в АРМ «Брокер» | ❓ неизвестно (ключевой вопрос кастдева!) | Если есть XML/XLS-импорт — наш экспорт станет «подачей за 2 минуты» без всякого API |
| XML R.055 (Решение 75) | Генерация возможна уже сейчас — формат публичен | Юридически единый для ЕАЭС; KEDEN (КЗ) уже принимает загрузку — ждать/лоббировать аналог в КР |
| Печатная форма/XLSX + копи-режим | ✅ доступно немедленно | Основной канал MVP |
| Browser-расширение (автозаполнение полей АРМ «Брокер» из нашего JSON) | R&D | Технически реально, если АРМ — веб; риски: изменение DOM, отношение ГТС. Юзер подаёт сам под своей ЭЦП — правовой риск низкий, но репутационный аспект обсудить ❓ |
| Реестры TULPAR (публичные) | ✅ можно проверять номера/статусы разрешительных документов по коду ТН ВЭД и ИНН (скрейпинг/поиск) | Киллер-валидация графы 44: «СГР №… не найден / приостановлен / код ТН ВЭД в сертификате не совпадает» |
| Курсы НБКР (графа 23) | ✅ публичные, ежедневные | Обязательный фид для расчёта стоимости |
| Тундук (ИНН → реквизиты) | ❓ доступ бизнесу по договору | Автозаполнение граф 8/9/14 по ИНН |

## 7. План верификации (кастдев с брокерами/декларантами — 30 минут разговора)

Критичные вопросы, которые закрывают все ❓ выше:

1. **АРМ «Брокер»:** это веб или десктоп? Есть ли импорт из файла (XML/XLS)?
   Сколько времени занимает ввод одной ДТ на 5/20/100 позиций? Что бесит?
2. Актуальные тарифы АРМ (всё ещё 150/100 сом за лист?) и порядок договора с ГП.
3. Какая ЭЦП используется (УЦ Инфоком/Тундук? ГТС-специфичная?), как получали.
4. Работает ли уже авторегистрация/автовыпуск? Какой % ДТ проходит без инспектора?
5. Сколько ДТ в месяц оформляет один декларант; сколько компания; средняя цена
   услуги за ДТ для клиента (сомов) — вилки по сложности.
6. Как сейчас проверяют разрешительные (руками в TULPAR?); были ли отказы из-за
   графы 44.
7. Частота КТС; как готовятся к защите стоимости.
8. Готовы ли платить за: (а) классификацию с обоснованием, (б) авточерновик ДТ
   из инвойса, (в) проверки перед подачей. Сколько.

Способ: 5–7 интервью через Ассоциацию таможенных брокеров КР (член ТПП КР) +
брокеры у постов «Бишкек—Северный»/аэропорт «Манас».
