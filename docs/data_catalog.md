# Справочник данных FEAP (Data Catalog)

> **Цель документа.** База данных — это **истина** (source of truth) для
> классификатора. Код никогда не принимает решений, которые не подтверждены
> строкой в БД. Этот справочник перечисляет все внешние и внутренние данные,
> которые мы парсим, собираем и загружаем в БД: природу данных, структуру,
> источник, формат обмена и **необходимую частоту обновления**.
>
> Пользуйтесь им как чеклистом при аудите актуальности. Для каждого фида
> явно указан «триггер обновления» — условие, при котором данные устаревают
> и требуют повторного прогона пайплайна.

---

## 1. Обзор

Все данные делятся на **четыре класса** по происхождению:

| Класс                    | Описание                                                                                   | Пример                          |
|--------------------------|--------------------------------------------------------------------------------------------|---------------------------------|
| **External — автомат**   | Скачиваются скриптами с публичных сайтов (EEC, TWS, sudact).                                | ETT PDF, Excel, HTML ед. изм.   |
| **External — ручной**    | Скачиваются/получаются вручную (нет стабильного HTTP-интерфейса / защищено токеном).        | NTM товарные списки (docx)      |
| **Curated — hardcode**   | Захардкожены в Python-скриптах: юридически стабильные и редко меняются.                     | ОПИ, секции, типы НТР, ст. 289 НК КР, ст. 336 НК КР |
| **Curated — JSON seed**  | Ведутся вручную как JSON-файл в репозитории, но содержат привязки к внешним НПА.            | `data/ntm_seed.json`            |

Пайплайн сборки (см. README раздел «Структура проекта»):

```
download/  → parse/  → build/  →  seed/   →  PostgreSQL
   PDF         JSON      tree.json    INSERT/UPDATE
```

## 2. Справочники по каждому фиду

Для каждого фида указаны: **Природа → Источник → Формат → Промежуточный
артефакт → Целевая таблица БД → Частота обновления → Триггер обновления**.

### 2.1. ETT номенклатура (дерево ТН ВЭД) — PDF ЕЭК

| Поле            | Значение                                                                                              |
|-----------------|-------------------------------------------------------------------------------------------------------|
| **Природа**     | Официальная иерархия ТН ВЭД ЕАЭС: раздел → группа → позиция → субпозиция → подсубпозиция.              |
| **Источник**    | https://eec.eaeunion.org/comission/department/catr/ett/ — 96 PDF-файлов по группам (01–97 без 77).     |
| **URL-ключи**   | Вшиты в `scripts/download/ett_pdfs.py` (`ETT_URLS`). Путь в URL меняется при публикации ревизии.       |
| **Формат**      | PDF с текстом (не скан). Каждый файл — один группа.                                                    |
| **Скачиваются** | `scripts/download/ett_pdfs.py` → `data/ett_pdfs/ru.NN.pdf`                                             |
| **Парсер**      | `scripts/parse/ett_nomenclature.py` (PyMuPDF/fitz) → `data/parsed/nomenclature.json`                   |
| **Структура JSON** | `{groups, positions, subpositions, leaves}` + `meta.parsed_at`. Субпозиции содержат `virtual_parents` (дешированные родительские узлы без собственного кода) — нужны для разрешения коллизий имён. |
| **БД**          | Имена узлов из `nomenclature.json` попадают в `tnved_tree.name` / `name_full` через `scripts/build/tree.py`. |
| **Объём**       | 20 236 узлов (21 раздел / 96 групп / 1 228 позиций / 5 612 субпозиций / 13 279 листьев).                |
| **Частота обновления** | **Ежемесячно проверять** — ЕЭК периодически публикует изменения (вшитые URL содержат даты, напр. `ru.11_2022_08.03.2026.pdf`). |
| **Триггер**     | (а) Решение Совета ЕЭК об изменении ТН ВЭД; (б) появление нового суффикса-даты в URL на сайте ЕЭК; (в) расхождение `meta.parsed_at` и даты последнего Решения Совета ЕЭК. |
| **Как обновить**| 1. Вручную сверить URL в `ETT_URLS` с актуальными на сайте ЕЭК (путь `catr/ett/ru.2022/...`). 2. `python scripts/download/ett_pdfs.py` (с удалением старых PDF или перезапуском с новыми URL). 3. `python scripts/parse/ett_nomenclature.py`. 4. `python scripts/build/tree.py` → `python scripts/seed/db.py` (требует `TRUNCATE tnved_tree CASCADE`). |

### 2.2. Ставки ввозных пошлин (ЕТТ) — TWS Excel

| Поле            | Значение                                                                                              |
|-----------------|-------------------------------------------------------------------------------------------------------|

| **Источник**    | tws.by — приобретённый/выгруженный Excel-файл. Имя содержит дату снимка: `TWS_TNVED_2026-02-17.xlsx`.  |
| **Формат**      | Excel (xlsx), лист `ТНВЭД`. Разделитель уровней иерархии в имени — символ `🠺` (U+1F87A).               |
| **Колонки**     | `code_10` (10 цифр), `name_with_arrows`, `duty_rate` (строка, напр. `"5%"` или сложносоставная), `link`.|
| **Парсер**      | `scripts/parse/excel.py` → `data/parsed/leaves.json` (список из 13 279 объектов).                      |
| **Структура**   | `code` / `code_formatted` / `group_code` / `position_code` / `subposition_code` / `code_8` / `name_parts` (split по `🠺`) / `name_full` / `name_leaf` / `duty_rate`. |
| **БД**          | `tnved_tree.duty_rate` (только для `level=4, is_leaf=true`). Имена листьев — `tnved_tree.name`.        |
| **Частота обновления** | **Раз в 1–3 месяца** — ставки пересматриваются Решениями Совета ЕЭК несколько раз в год. Дата снимка в имени файла — источник истины. |
| **Триггер**     | (а) Публикация нового Решения Совета ЕЭК об изменении ставок ЕТТ; (б) клиент запросил классификацию, а `duty_rate` в БД старше 3 месяцев. |
| **Как обновить**| 1. Получить новый Excel от tws.by, положить в `data/TWS_TNVED_YYYY-MM-DD.xlsx` (старый можно удалить — скрипт ищет по glob `TWS_TNVED*.xlsx`). 2. `python scripts/parse/excel.py` → `scripts/build/tree.py` → `scripts/seed/db.py` (с `TRUNCATE`). |
| **Риск**        | Excel — платный/коммерческий формат. Альтернатива — R12 TWS.BY API (не интегрирован). При потере доступа к tws.by пайплайн нужно переписать на парсинг PDF ЕТТ (в `parse/ett_nomenclature.py` ставки сейчас не извлекаются). |

| **Природа**     | Юридически значимые примечания к разделам (I–XXI) и группам (01–97). Бывают `inclusive`, `exclusive`, `definition`, `general`. Исключающие → триггер backtracking в каскаде. |
| **Источник**    | Те же PDF, что и в §2.1 (`data/ett_pdfs/ru.NN.pdf`). Примечания расположены на первых страницах каждого PDF, перед таблицей кодов. |

| **Структура**   | Массив `{scope_type: section|group, scope_code, note_number, note_type, note_text, references_to}`.   |
| **Классификация** | По ключевым словам: `не включа*` → `exclusive`; `включа*`/`относ*` → `inclusive`; `означа*`/`определен*`/`термин` → `definition`; иначе → `general`. |
| **БД**          | `tnved_notes`                                                                                          |
| **Объём**       | 52 раздельных примечания + 481 групповых (≈533 записи на ~130 уникальных scope-кодов).                 |
| **Частота обновления** | **Синхронно с §2.1** — живут в тех же PDF-файлах.                                              |
| **Триггер**     | Пересборка §2.1. Если PDF обновлён — всегда перезапускать и парсер примечаний.                         |
| **Как обновить**| `python scripts/parse/notes_pdf.py` → `scripts/seed/db.py` (skip-if-exists: предварительно `TRUNCATE tnved_notes`). |

### 2.4. Пояснения (ПСН) — PDF ЕЭК

| Поле            | Значение                                                                                              |
|-----------------|-------------------------------------------------------------------------------------------------------|
| **Природа**     | Расширенные пояснения к позициям и субпозициям (официальный комментарий ЕЭК к ТН ВЭД). Используются на L3/L4 каскада — подгружаются **напрямую по коду**, не через RAG. |
| **Источник**    | https://eec.eaeunion.org/upload/files/catr/psn/psnNN.pdf — 97 файлов (psn01.pdf … psn97.pdf).          |
| **Скачиваются** | `scripts/download/psn_pdfs.py` → `data/pdfs/psn/`                                                      |
| **Парсер**      | `scripts/parse/explanatory_pdfs.py` → `data/parsed/explanatory_notes.json`                             |
| **Структура**   | Массив `{code, group_code, code_level (1/2/3), section_type (general|includes|excludes), title, content, content_tokens, source_file}`. Разбивка по секциям, **не по чанкам** — полный текст секции хранится целиком. |
| **БД**          | `tnved_explanatory_notes` (код + уровень + тип секции + полный `content`). Вектор-колонка `embedding` присутствует в модели `rag/`, но **не заполняется** (RAG зарезервирован под прецеденты). |

| **Частота обновления** | **Редко** — ЕЭК обновляет пояснения пакетно, несколько раз в год. В отличие от номенклатуры, URL стабильны (без дат). |
| **Триггер**     | (а) Официальное сообщение ЕЭК о новой редакции пояснений; (б) систематические ошибки модели на определённой группе, разрешаемые после сверки с актуальным PDF. |
| **Как обновить**| `python scripts/download/psn_pdfs.py` (перезапишет устаревшие PDF при удалении) → `python scripts/parse/explanatory_pdfs.py` → `python scripts/seed/db.py`. |

|-----------------|-------------------------------------------------------------------------------------------------------|

### 2.8. Меры нетарифного регулирования — curated JSON

|-----------------|-------------------------------------------------------------------------------------------------------|
| **Природа**     | Перечень действующих мер НТР ЕАЭС: технические регламенты (ТР ТС / ЕАЭС), лицензирование, сан-/вет-/фитоконтроль, маркировка и др. Привязка меры к 2–4-значным кодам ТН ВЭД + квалификатор (`product_description`) для LLM-верификации. |

| **Загрузчик**   | `scripts/seed/ntm_data.py` (idempotent, `--force` для ре-seed).                                        |
| **БД**          | `ntm_measures` + `ntm_measure_codes` (M:N). Тип меры → `ntm_measure_types.id` по полю `kind`.          |

| **Частота обновления** | **Раз в квартал.** Новые ТР ТС и решения ЕЭК выходят несколько раз в год. |
| **Триггер**     | (а) Публикация нового Решения Коллегии ЕЭК или ТР ТС; (б) истекла `valid_to` у существующей меры; (в) пользовательская жалоба на пропущенную меру. |
| **Пробелы (важно!)** | ✘ Национальные меры КР (`scope='national'`, `country_code='KG'`) — **не заполнены**. ✘ Интеграция TWS.BY R12 API — **не сделана** (платный токен). ✘ Русскоязычные PDF перечней товаров на сайте ЕЭК — **сканы**, OCR не прогонялся; DOCX-варианты доступны только для KG/KZ/BY версий. |
| **Как обновить**| Редактировать `data/ntm_seed.json`, обновить `_updated`, затем `python scripts/seed/ntm_data.py --force`. |

## 4. Профили обновления — когда что делать

### Быстрый (изменился только Excel ставок)
```
python scripts/parse/excel.py
python scripts/build/tree.py
docker compose exec db psql -U feap -d feap -c "TRUNCATE tnved_tree CASCADE; TRUNCATE tnved_opi;"
docker compose run --rm seed
```
Сохранится: примечания (`tnved_notes`), пояснения (`tnved_explanatory_notes`), НТР, НДС-освобождения, акцизы. **Сессии и job-ы не трогаются.**

### Средний (изменились PDF ЕЭК — номенклатура/примечания)
```
python scripts/download/ett_pdfs.py   # после ручной актуализации ETT_URLS
python scripts/parse/ett_nomenclature.py
python scripts/parse/notes_pdf.py
python scripts/parse/excel.py
python scripts/build/tree.py
# truncate + seed как выше
```

### Средний (изменились пояснения ПСН)
```
python scripts/download/psn_pdfs.py
python scripts/parse/explanatory_pdfs.py
# seed_db скипнет заполненные таблицы, поэтому:
docker compose exec db psql -U feap -d feap -c "TRUNCATE tnved_explanatory_notes;"
docker compose run --rm seed
```

### Точечный (добавлена мера НТР)
```
# редактируем data/ntm_seed.json, меняем _updated
python scripts/seed/ntm_data.py --force
```

### Точечный (изменилась ст. 336 НК КР — акцизы)
```
# редактируем scripts/seed/excise_rates.py
docker compose exec db psql -U feap -d feap -c "TRUNCATE excise_rates;"
python scripts/seed/excise_rates.py
```

### Точечный (освобождение от НДС)
```
# редактируем scripts/seed/vat_exemptions.py
docker compose exec db psql -U feap -d feap -c "TRUNCATE vat_exemptions;"
python scripts/seed/vat_exemptions.py
```

## 6. Принципы

1. **БД — истина.** Никаких in-memory хардкодов в рантайме классификации. Всё, что нужно на L0–L5, читается из PostgreSQL.
2. **Idempotency.** Все seed-скрипты безопасны при повторном запуске — `TRUNCATE` делается явно при необходимости.
3. **Датированные артефакты.** Excel (дата в имени), JSON-seed (`_updated`), PDF-URL (суффикс даты) — везде, где можно, фиксируем дату снимка источника.
4. **Ручная курация отмечена явно.** `ntm_seed.json`, `vat_exemptions.py`, `excise_rates.py`, `ntm_types.py`, `sections.json`, `opi.py` — источник «мы сами».
5. **Параллельные источники.** Имена узлов из `nomenclature.json` (EEC PDF) сливаются со ставками из `leaves.json` (TWS Excel) в `tree.json` — для 10-значных листьев. Это намеренное объединение двух источников.
