## 4. Исполнители и маршрутизаторы

**Исполнители.** Основной — `liquid/d1.1`, второй — `typesafe/jev-1.14`. На разметке дополнительно проверяются:

- `microsoft/microsoft-decision-1`;
- `cloudflare/clef-flash`;
- `upstage/solar-decide`;
- `inception/mercury-decide`;
- `openai/gpt-6-luna-decisions`.

Все вопросы банка уходят одним запросом. Ответ — наиболее вероятный вариант, без порогов; распределение сохраняется
целиком.

**Маршрутизаторы.** Оценки логарифмические; top-k — по убыванию оценки, при равенстве — по коду группы. Параметры:
eps = 0,05, alpha = 1, prior по группам равномерный.

| | Маршрутизатор | Как считается |
|---|---|---|
| R1 | Закон | Совместимость распределений ответов с профилем группы |
| R2 | Данные | Наивный Байес на train_d1 с мягкими счётчиками по распределениям |
| **R3** | **Закон + данные — основной** | R1 + R2 на ответах d1.1 |
| | Сравнение исполнителей | R3 на первых 1 000: Jev против d1.1 |
| | Базовая линия BM25 | Top-10 решений обучающего пула по BM25; оценка группы — сумма их баллов |
| | Исследовательский | R3 + BM25 |

**Каскад** для сравнения — группа его итогового кода: R0 на dev, C0 на fresh. Отдельно приводится сравнение с C1.

**Известный дефект справочника.** У групп 50, 72, 84 и 86 в `tnved_tree` вместо наименования стоит «Группа NN». Это
заглушка `scripts/build/tree.py`: парсер PDF не извлёк названия. На L2 каскад видел эти заглушки во всех прогонах
R0, C0 и C1. Маршрутизаторы фактов от наименований в базе не зависят.

## 5. Метрики и решение

### Фаза A — по каждому вопросу

- доля «нельзя определить» на train_d1 и train_jev;
- согласие d1.1 и Jev на train_jev;
- точность против разметки, у условных вопросов — ещё и на описаниях, к которым вопрос относится;
- взаимная информация ответа d1.1 с группой эталона на train_d1.

**G3.** Из 10 базовых вопросов, то есть без условных, хотя бы 8 проходят оба условия для d1.1:

- «нельзя определить» ≤ 15% на train_d1;
- точность против разметки ≥ 80%.

### Фаза B — основной маршрутизатор R3 на 293 кейсах

- **G1.** На ошибках каскада в группе эталон в top-3 хотя бы в 50% случаев.
- **G2.** Top-3 по всем кейсам ≥ 85%.

Вторичные метрики:

- top-1;
- эталон выше группы каскада;
- на верных кейсах каскада маршрутизатор предлагает другую группу;
- при несогласии прав маршрутизатор;
- итог, если всегда слушать маршрутизатор;
- сравнение с BM25 и каскадом C1.

Для G1 и G2 — 95%-интервалы, бутстреп по кейсам: 10 000 повторов, seed 20261105.

| G3 | G1 и G2 | Дальше |
|---|---|---|
| выполнено | выполнены | Фаза C: факты и кандидаты групп в L1–L2 каскада, предрегистрированный сквозной тест на новой свежей выборке, ≈ $7–8 |
| выполнено | не выполнены | Факты — для уточняющих вопросов пользователю и нетарифных мер; для навигации — нет. Разбор, каких фактов не хватает |
| не выполнено | — | Банк v2: переписать непрошедшие вопросы до любых других шагов |
