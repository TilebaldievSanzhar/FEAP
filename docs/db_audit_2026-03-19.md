## 2. Критические проблемы

### 2.1 CRITICAL: `tnved_notes` — 0 строк (примечания к разделам и группам)

**Статус**: Таблица создана (миграция 001), но данных нет.

- `data/pdfs/notes/` — **0 файлов** (PDF не загружены)
- `data/parsed/notes.json` — **не существует**
- `scripts/parse_notes_pdf.py` — скрипт парсинга существует, но нечего парсить
- `seed_db.py` — **не содержит логики** загрузки `tnved_notes`

**Влияние на каскад**:
- **L1 (Раздел)**: Не получает примечания к разделам → не проверяются исключения → неверная классификация
- **L2 (Группа)**: Не получает примечания к группам → пропускаются перенаправления между группами
- **L3 (Позиция)**: Не получает примечания к группе → определения терминов недоступны
- **L4 (Субпозиция)**: Примечания к субпозициям недоступны

**Это блокирующая проблема** — без примечаний каскадный классификатор не может корректно применять ОПИ Правило 1.

### 2.2 HIGH: `vat_rate` — NULL у всех 13 279 листьев

Колонка `vat_rate` не заполнена **ни у одного** узла. Данных о ставке НДС нет ни в tree.json, ни в leaves.json.

**Влияние**: Этап валидации (пост-обработка) не может выдать ставку НДС. Используется `VAT_RATE_DEFAULT = "12%"` из config, что корректно для КР, но не для исключений.

> Примечание: `vat_exemptions` (8 строк) покрывает освобождения, но базовая ставка в `tnved_tree.vat_rate` не записана.

### 2.3 HIGH: 28 «зависших» сессий классификации

Все 28 сессий в `classification_sessions` старше TTL (30 минут). Самая старая: 2026-03-17, самая новая: 2026-03-18.

**Нет механизма очистки** — TTL проверяется только при загрузке сессии, автоматического удаления (`cron` / `pg_cron`) не настроено.
