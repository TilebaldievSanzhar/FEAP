# Спецификация данных по коду ТН ВЭД ЕАЭС

> Контекст: продукт запускается в **Кыргызской Республике** (член ЕАЭС).
> Документ описывает, какие данные должен возвращать эндпоинт информации по коду ТН ВЭД, их источники и приоритеты реализации.

---

## 1. Общая структура ответа

Эндпоинт по коду ТН ВЭД должен возвращать данные, сгруппированные в следующие блоки:

1. **Идентификация кода** — наименование, иерархия, статус
2. **Таможенные платежи** — пошлина, НДС, акциз
3. **Единицы измерения** — основная и дополнительная
4. **Нетарифное регулирование** — запреты, ограничения, разрешительные документы
5. **Преференции и льготы** — ЗСТ, тарифные преференции, тарифные квоты
6. **Справочные данные** — примечания, пояснения, ссылки на НПА

## 3. Блок 2: Таможенные платежи

### 3.1. Ставка ввозной таможенной пошлины (ЕТТ ЕАЭС)

**Что это:** Единый таможенный тариф, одинаковый для всех стран ЕАЭС. Устанавливается решениями Совета ЕЭК.

**Виды ставок:**
- **Адвалорная** — процент от таможенной стоимости (например, `7.5%`)
- **Специфическая** — фиксированная сумма за единицу (например, `0.3 EUR/кг`)
- **Комбинированная** — адвалорная, но не менее специфической (например, `10%, но не менее 0.5 EUR/кг`)

**Источник:** Excel tws.by (уже загружен) → колонка ставки ЕТТ.

**Статус:** ✅ Реализовано.

---

### 3.2. НДС при импорте

**Специфика Кыргызстана:**
- Стандартная ставка НДС: **12%** (НК КР, ст. 281)
- Это ниже, чем в России (20%) и Беларуси (20%)
- Освобождение от НДС при импорте (ст. 289 НК КР):
  - Лекарственные средства (по перечню Правительства)
  - Технологическое оборудование (по перечню)
  - Товары для инвалидов
  - Гуманитарная помощь
  - Некоторые продовольственные товары (мука, растительное масло — периодически, по решениям Правительства)

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `vat_rate` | Ставка НДС | `12%` |
| `vat_exemption` | Освобождение от НДС | `null` или `"ст. 289 п.X НК КР"` |
| `vat_exemption_note` | Пояснение к освобождению | `"Лекарственные средства по перечню..."` |

**Источник данных:**
- Базовая ставка 12% — захардкодить
- Перечни освобождений — Постановления Правительства КР, требуют ручного ведения справочника

**Приоритет:** 🔴 Высокий — нужен в MVP.

### 3.3. Акциз

**Что это:** Косвенный налог на отдельные категории товаров. В Кыргызстане акцизы регулируются разделом IX НК КР (ст. 289–313).

**Подакцизные товары в КР:**
- Этиловый спирт и алкогольная продукция (группы 22)
- Пиво (2203)
- Табачные изделия (группа 24)
- Нефтепродукты: бензин, дизтопливо (2710)
- Автомобили легковые (8703) — только с объёмом двигателя более 3000 см³

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `excise_applicable` | Подакцизный ли товар | `true` / `false` |
| `excise_rate` | Ставка акциза | `100 сом/литр` |
| `excise_base` | База для расчёта | `литр безводного спирта` |
| `excise_legal_ref` | Ссылка на НПА | `НК КР, ст. 296` |

**Источник данных:**
- НК КР + Постановления Правительства
- Перечень подакцизных товаров ограничен (~20-30 кодов на уровне 4-6 знаков), можно вести вручную

**Приоритет:** 🟡 Средний — ограниченный набор товаров, но важен для них.

### 3.4. Вывозная (экспортная) таможенная пошлина

**Специфика Кыргызстана:**
- В КР вывозные пошлины практически не применяются (в отличие от РФ)
- Исключение: отдельные виды сырья и лом металлов — периодически вводятся временные вывозные пошлины

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `export_duty_rate` | Ставка вывозной пошлины | `null` или `"10%"` |
| `export_duty_note` | Пояснение | `"Временная мера до 31.12.2026"` |

**Приоритет:** 🟢 Низкий — мало применимо.

---

### 3.5. Антидемпинговые, компенсационные и специальные защитные пошлины

**Что это:** Дополнительные пошлины, вводимые ЕАЭС в отношении конкретных товаров из конкретных стран.

**Примеры действующих мер ЕАЭС (на уровне союза, применяются и в КР):**
- Антидемпинговая пошлина на гербициды из ЕС (3808)
- Специальная защитная пошлина на трубы из нержавеющей стали из Китая (7304, 7306)
- Компенсационная пошлина на отдельные виды стали из Украины

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `special_duties` | Массив специальных пошлин | `[...]` |
| `special_duties[].type` | Тип: `antidumping` / `countervailing` / `safeguard` | `"antidumping"` |
| `special_duties[].rate` | Ставка | `"23.1%"` |
| `special_duties[].country` | Страна происхождения | `"Китай"` |
| `special_duties[].legal_ref` | Решение ЕЭК | `"Решение Коллегии ЕЭК от ..."` |
| `special_duties[].valid_to` | Срок действия | `"2027-03-15"` |

**Источник данных:**
- Решения Коллегии/Совета ЕЭК — публикуются на eurasiancommission.org
- ~50-70 действующих мер, меняются 3-5 раз в год
- Требуют привязки к кодам ТН ВЭД + странам

**Приоритет:** 🟡 Средний — важно для точного расчёта, но сложно поддерживать в актуальном состоянии.

## 5. Блок 4: Нетарифное регулирование

Самый объёмный и сложный блок. Определяет, какие разрешительные документы нужны для ввоза/вывоза товара.

### 5.1. Технические регламенты ЕАЭС (ТР ЕАЭС / ТР ТС)

**Что это:** Обязательные требования безопасности. Для ввоза товара, подпадающего под ТР, нужен сертификат или декларация соответствия.

**Основные ТР, действующие в ЕАЭС:**
- ТР ТС 004/2011 — Низковольтное оборудование
- ТР ТС 005/2011 — Безопасность упаковки
- ТР ТС 007/2011 — Детские товары
- ТР ТС 008/2011 — Игрушки
- ТР ТС 009/2011 — Парфюмерно-косметическая продукция
- ТР ТС 010/2011 — Машины и оборудование
- ТР ТС 011/2011 — Лифты
- ТР ТС 017/2011 — Лёгкая промышленность
- ТР ТС 019/2011 — СИЗ
- ТР ТС 020/2011 — Электромагнитная совместимость
- ТР ТС 021/2011 — Пищевая продукция
- ТР ТС 025/2012 — Мебель
- ТР ЕАЭС 037/2016 — Ограничение опасных веществ в электронике
- ТР ЕАЭС 043/2017 — Пожарная безопасность
- ...и ещё ~30 регламентов

**Привязка к ТН ВЭД:** Каждый ТР имеет перечень кодов ТН ВЭД, на которые распространяется (публикуется как приложение к решению ЕЭК).

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `technical_regulations` | Массив применимых ТР | `[...]` |
| `technical_regulations[].code` | Номер ТР | `"ТР ТС 004/2011"` |
| `technical_regulations[].name` | Название | `"О безопасности низковольтного оборудования"` |
| `technical_regulations[].doc_type` | Требуемый документ | `"сертификат"` или `"декларация"` |

**Источник:**
- Перечни кодов к каждому ТР — решения ЕЭК (официальные приложения)
- Обновляются при изменении ТН ВЭД (обычно 1-2 раза в год)

**Приоритет:** 🔴 Высокий — критично для участников ВЭД.

**Специфика КР:** Кыргызстан присоединяется к единой системе маркировки ЕАЭС поэтапно. Национальный оператор — ГП «Инфоком». На данный момент обязательная маркировка введена для ограниченного перечня товаров.

## 6. Блок 5: Преференции и льготы

### 6.1. Тарифные преференции для развивающихся стран

**Что это:** Сниженные ставки пошлин для товаров из развивающихся и наименее развитых стран (система GSP ЕАЭС).

- **Развивающиеся страны** (103 страны) — ставка = 75% от ЕТТ
- **Наименее развитые страны** (49 стран) — ставка = 0%
- Применяется только к товарам из определённого перечня кодов ТН ВЭД (Решение КТС № 130)

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `gsp_eligible` | Подпадает ли код под преференции GSP | `true` / `false` |
| `gsp_rate_developing` | Ставка для развивающихся стран | `5.625%` (75% от 7.5%) |
| `gsp_rate_ldc` | Ставка для наименее развитых | `0%` |

**Источник:** Решение Совета ЕЭК № 47 (перечень товаров) + Решения о списках стран.

**Приоритет:** 🟡 Средний.

---

### 6.2. Зоны свободной торговли (ЗСТ)

**Что это:** Двусторонние/многосторонние соглашения, предусматривающие нулевые или сниженные пошлины.

**Действующие ЗСТ ЕАЭС (применяются и в КР):**
- **СНГ** — большинство товаров 0% (между странами СНГ)
- **Вьетнам** — ЗСТ ЕАЭС-Вьетнам (с 2016)
- **Сербия** — ЗСТ ЕАЭС-Сербия (с 2021)
- **Иран** — временное соглашение (ограниченный перечень)
- **Сингапур** — ЗСТ ЕАЭС-Сингапур (с 2022, ратификация)
- **В процессе:** Египет, Индия, ОАЭ, Индонезия

**Специфика КР:** Кыргызстан также имеет двусторонние соглашения в рамках СНГ.

**Условие применения:** Наличие сертификата о происхождении товара (форма СТ-1 для СНГ, форма EAV для Вьетнама и т.д.).

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `fta_preferences` | Массив применимых ЗСТ | `[...]` |
| `fta_preferences[].agreement` | Название ЗСТ | `"ЕАЭС-Вьетнам"` |
| `fta_preferences[].rate` | Ставка по ЗСТ | `"0%"` |
| `fta_preferences[].certificate` | Требуемый сертификат | `"форма EAV"` |
| `fta_preferences[].conditions` | Условия | `"Правила определения страны происхождения..."` |

**Приоритет:** 🟢 Низкий для MVP — зависит от страны происхождения, усложняет логику.

---

### 6.3. Тарифные квоты

**Что это:** Пониженная ставка пошлины в пределах установленного объёма (квоты). Сверх квоты — полная ставка ЕТТ.

**Примеры в ЕАЭС:**
- Мясо КРС (0201, 0202) — квоты по странам
- Мясо свинины (0203)
- Мясо птицы (0207)
- Молочная сыворотка (0404)

**Специфика КР:** Квоты распределяются между странами ЕАЭС. КР получает свою долю.

**Поля:**

| Поле | Описание | Пример |
|------|----------|--------|
| `tariff_quota` | Действует ли тарифная квота | `true` / `false` |
| `quota_in_rate` | Ставка в пределах квоты | `"15%"` |
| `quota_out_rate` | Ставка сверх квоты | `"55%"` |
| `quota_volume` | Объём квоты | `"1 500 тонн"` |

**Приоритет:** 🟢 Низкий.

## 9. Дорожная карта реализации

### Фаза 1 — MVP (текущая)

| Данные | Источник | Сложность | Статус |
|--------|----------|-----------|--------|
| Код + наименование + цепочка | Excel tws.by → БД | Низкая | ✅ Готово |
| Ставка ввозной пошлины (ЕТТ) | Excel tws.by → БД | Низкая | ✅ Готово |
| Единицы измерения | Excel tws.by → БД | Низкая | ⬜ Нужно извлечь из Excel |
| НДС (12% КР + исключения) | Хардкод + справочник | Низкая | ⬜ |
| Дата актуальности данных | Метаданные загрузки | Низкая | ⬜ |

### Фаза 2 — Нетарифные меры (базовые)

| Данные | Источник | Сложность |
|--------|----------|-----------|
| Технические регламенты (ТР) | Перечни ЕЭК → справочная таблица | Средняя |
| Акцизы | НК КР → справочная таблица (~30 кодов) | Низкая |
| Санитарный контроль | Решение КТС № 299 → справочная таблица | Средняя |
| Ветеринарный контроль | Решение КТС № 317 → справочная таблица | Средняя |
| Фитосанитарный контроль | Решение КТС № 318 → справочная таблица | Средняя |

### Фаза 3 — Расширенные данные

| Данные | Источник | Сложность |
|--------|----------|-----------|
| Лицензирование | Решения ЕЭК → справочная таблица | Средняя |
| Антидемпинговые/специальные пошлины | Решения ЕЭК → справочная таблица + страна | Высокая |
| Преференции (GSP) | Решение КТС № 130 | Средняя |
| ЗСТ | Тексты соглашений | Высокая |
| Маркировка | Решения ЕЭК + национальные НПА | Средняя |
| Тарифные квоты | Решения ЕЭК | Средняя |

## 10. Особенности Кыргызстана (резюме)

| Аспект | Отличие от РФ/РБ |
|--------|-------------------|
| **НДС** | 12% (не 20%) |
| **Подакцизные товары** | Уже перечень, но ставки национальные |
| **Вывозные пошлины** | Практически не применяются |
| **Маркировка** | Поэтапное внедрение, пока ограниченный перечень |
| **Орган выдачи лицензий** | МЭК КР |
| **Таможенный орган** | ГТС при Правительстве КР (customs.kg) |
| **Национальные льготы** | Свои перечни освобождений от НДС, свои инвестиционные льготы |
| **Валюта платежей** | Кыргызский сом (KGS) |
| **ЕТТ** | Одинаковый с остальными странами ЕАЭС (единый тариф) |
| **Нетарифные меры ЕАЭС** | Применяются в полном объёме |
