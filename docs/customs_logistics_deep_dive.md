## 1. ОТВЕТ НА КЛЮЧЕВОЙ ВОПРОС: ПОЧЕМУ ТАМОЖНЯ/ВЭД И ЛОГИСТИКА РАЗДЕЛЕНЫ?

### 1.1 Краткий ответ: Это ошибка сегментации

Ты абсолютно прав — **разделение искусственное**. В реальном бизнесе это единый операционный поток. Вот почему:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        ЕДИНЫЙ ЦИКЛ ВЭД-ОПЕРАЦИИ                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  ЗАКУПКА → ЛОГИСТИКА → ТАМОЖНЯ → ЛОГИСТИКА → СКЛАД → ДИСТРИБУЦИЯ           │
│     ↓          ↓           ↓          ↓         ↓          ↓                │
│  Контракт   Перевозка   ДТ/Пошлины  Доставка  Хранение   Продажа           │
│  Инвойс    CMR/BoL     ТН ВЭД      Tracking   Учет      Отчетность         │
│                                                                              │
│  ←──────────────── ОДНИ И ТЕ ЖЕ ДОКУМЕНТЫ ──────────────────→              │
│  ←──────────────── ТЕ ЖЕ КОНТРАГЕНТЫ ───────────────────────→              │
│  ←──────────────── ЕДИНАЯ ТРАНЗАКЦИЯ ───────────────────────→              │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 Почему исторически разделяли:

| Причина | Почему это устарело |
|---------|---------------------|
| **Разные лицензии** — таможенный брокер требует лицензию ГТС | AI-продукт не требует лицензии брокера, это SaaS-инструмент |
| **Разные компетенции** — таможенники vs логисты | AI объединяет domain knowledge в одном продукте |
| **Разные системы** — ЕАИС vs TMS | Интеграционный слой решает эту проблему |
| **Разные клиенты** — брокеры vs экспедиторы | 80% клиентов — это одни и те же компании |

### 1.3 Стратегическое решение: ОБЪЕДИНЯЕМ

**Позиционирование:** Не "таможенный софт" и не "логистический софт", а **"AI-платформа для внешнеэкономической деятельности"** — единое решение для всего цикла импорта/экспорта.

**Это даёт:**
- Единый data layer = лучше AI-модели
- Cross-sell возможности
- Выше LTV клиента
- Сильнее конкурентное преимущество
- Lock-in эффект

## 5. ПРОДУКТОВАЯ СТРАТЕГИЯ

### 5.1 Product Vision

**"AI-powered единое окно для ВЭД: от инвойса до склада"**

One-liner: "Делаем импорт/экспорт таким же простым, как заказ на маркетплейсе"

### 5.2 Product Principles

1. **AI-first, not AI-bolted** — AI в ядре, не как фича сбоку
2. **Automate the boring** — экономим время на рутине, а не заменяем эксперта
3. **Trust through transparency** — показываем reasoning, даём ссылки на НПА
4. **Integrate, not replace** — работаем с существующими системами (1С, TMS)
5. **Local-first** — ЕАЭС-специфика как конкурентное преимущество

### 6.2 RAG Pipeline для классификации ТН ВЭД

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    HS CODE CLASSIFICATION PIPELINE                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  INPUT: "Смартфон Apple iPhone 15 Pro Max, 256GB, синий, б/у"               │
│                                                                              │
│  STEP 1: QUERY ENHANCEMENT                                                   │
│  ├── Normalize: убираем бренд, цвет (не влияют на код)                      │
│  ├── Extract: "смартфон", "телефон мобильный", "256GB"                      │
│  └── Expand: synonyms ("сотовый телефон", "cellular phone")                  │
│                                                                              │
│  STEP 2: SEMANTIC RETRIEVAL (Vector DB)                                      │
│  ├── Query embeddings → top-20 relevant chunks from:                         │
│  │   • ТН ВЭД ЕАЭС 2022 (структура + примечания)                            │
│  │   • Пояснения к ТН ВЭД (ВТамО)                                           │
│  │   • Решения о классификации ЕЭК                                          │
│  │   • Судебные решения по спорам о классификации                           │
│  └── Re-rank by relevance                                                    │
│                                                                              │
│  STEP 3: LLM CLASSIFICATION                                                  │
│  ├── System prompt: "Ты эксперт по классификации товаров по ТН ВЭД ЕАЭС"   │
│  ├── Context: retrieved chunks                                               │
│  ├── Task: "Определи 10-значный код ТН ВЭД для данного товара"              │
│  └── Instructions:                                                           │
│      • Следуй ОПИ 1-6 (Основные правила интерпретации)                       │
│      • Дай top-5 наиболее вероятных кодов                                    │
│      • Для каждого кода укажи confidence (0-100%)                            │
│      • Объясни reasoning со ссылками на конкретные примечания                │
│                                                                              │
│  STEP 4: STRUCTURED OUTPUT                                                   │
│  ├── Parse LLM response into JSON                                            │
│  ├── Validate: codes exist in ТН ВЭД, format correct                         │
│  └── Enrich: add duty rates, restrictions, requirements                      │
│                                                                              │
│  OUTPUT:                                                                     │
│  {                                                                           │
│    "input_description": "Смартфон Apple iPhone 15 Pro Max...",              │
│    "classifications": [                                                      │
│      {                                                                       │
│        "hs_code": "8517120000",                                              │
│        "description": "Телефоны для сотовых сетей или других беспр. сетей",│
│        "confidence": 95,                                                     │
│        "reasoning": "Согласно примечанию 3 к группе 85...",                 │
│        "sources": ["ТН ВЭД гр.85 прим.3", "Решение ЕЭК от..."],             │
│        "duty_rate": "0%",                                                    │
│        "vat_rate": "12%"                                                     │
│      },                                                                      │
│      ...                                                                     │
│    ]                                                                         │
│  }                                                                           │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```
