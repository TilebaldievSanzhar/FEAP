# Повторная проверка четырёх замен эталонов v32

Проверка выполнена по запросу пользователя, без обращений к OpenRouter и без
новых прогонов. Проверяется соответствие исходных описаний номенклатуре,
а не совпадение с ответом модели. Исходный benchmark_100 не изменён.

Вывод: три замены обоснованы прямыми условиями веток при обычном техническом
прочтении описаний; четвёртая, H30, не должна считаться безусловно подтверждённой.
Ни один пункт не является обещанием 100% достоверности фактических характеристик
не предъявленного товара. Нужно различать ошибочность старого кода и достаточность
сведений для нового десятизначного кода.

## M06: стерилизованная говяжья тушёнка

Из описания: тушёнка, стерилизованная, жестяные банки 338 г, говядина 58%.
Замена: `1602501000` → `1602509501`.

Старый код находится в ветке сырых продуктов и смесей сырого с отварным мясом.
Дополнительное примечание 1 определяет сырые продукты через отсутствие достаточной
тепловой обработки. Это противоречит описанию стерилизованной тушёнки.
Новый код проходит через ветку готовых продуктов из мяса КРС, исключая солонину,
к продуктам в герметичных контейнерах. Содержание мяса 58% превышает порог 20%
из примечания 2; упаковка 338 г не соответствует условию ≤250 г для специальной
субпозиции гомогенизированных продуктов.

Замена обоснована при обычном значении «стерилизованная тушёнка в банках»:
готовые герметично укупоренные мясные консервы. Само по себе слово «банка»
не доказывает герметичность; если это свойство действительно неизвестно,
последнюю цифру нужно подтвердить по упаковке. Наличие соли в рецептуре
не превращает тушёнку в солонину.

Источник: [официальная группа 16, страницы PDF 1, 2 и 5](https://eec.eaeunion.org/comission/department/catr/ett/ru.2022/ru.16_2022_10.09.2023.pdf).

## M34: асинхронный трёхфазный двигатель 3 кВт

Замена: `8501522009` → `8501522001`.

В пределах одинакового диапазона номинальной выходной мощности >750 Вт и
≤7,5 кВт лист 2001 выделяет асинхронные двигатели, а 2009 — остальные.
Тип двигателя явно указан в исходном описании. Поэтому выбор остаточного
листа вместо конкретного противоречит известному признаку.

Для нового кода 3 кВт трактуются как номинальная выходная мощность двигателя.
В тексте кейса написано только «мощность 3 кВт». Это обычное техническое прочтение
характеристики двигателя, но сам тип мощности в кейсе формально не уточнён.
Если требуется строго замкнутое доказательство всех условий эталона, нужен паспорт
или подтверждение автора кейса, а не молчаливое дополнение исходного описания.

Источник: [официальная группа 85, страница PDF 11](https://eec.eaeunion.org/comission/department/catr/ett/ru.2022/ru.85_2022_05.07.2026.pdf).

## H29: новый дорожный дизельный самосвал, полная масса 25,2 т

Замена: `8704239809` → `8704239209`.

Старый код 9809 находится под родителем бывших в эксплуатации транспортных
средств. В описании отдельно и прямо указано, что самосвал новый.
Это непосредственное противоречие. Более того, исходное поле notes ошибочно
называет 8704239809 кодом новых транспортных средств — текст notes не является
нормативным источником и опровергается таблицей ЕТТ.

Новая ветка 920 относится к новым транспортным средствам. Полная масса 25,2 т,
а не грузоподъёмность 13 т, определяет диапазон >20 т. Дорожное назначение
явно отделяет товар от самосвалов для бездорожья. Специальные листья 9201/9202
описывают четырёхгусеничные машины с двумя ведущими тележками для иных задач;
обычному дорожному самосвалу для сыпучих грузов соответствует 9209.

При описанных свойствах замена подтверждается непосредственно структурой таблицы.
Источник: [официальная группа 87, страницы PDF 72, 75 и 76](https://eec.eaeunion.org/comission/department/catr/ett/ru.2022/ru.87_2022_22.01.2026.pdf).

## H30: Bluetooth-колонка, два динамика и пассивный излучатель

Предложенная замена: `8518210000` → `8518220009`.
Статус: **условная; безусловное подтверждение из отчёта v32 отозвано**.

Ветка 851821 относится к одиночным громкоговорителям, 851822 — к нескольким
громкоговорителям в одном корпусе. Исходный комментарий «портативная колонка
считается единым устройством» не является основанием игнорировать два динамика:
один корпус прямо предусмотрен текстом 851822. Пассивный излучатель не требуется
считать третьим громкоговорителем: в описании уже есть два динамика.

Однако [решение Коллегии ЕЭК №150 от 24.11.2020, опубликованное в ИПС «Әділет»](https://adilet.zan.kz/rus/docs/H20EK000150)
предусматривает 8518309500 для описанной в нём портативной системы с Bluetooth,
аккумулятором, громкоговорителем/громкоговорителями, микрофоном и возможностью
телефонного общения в режиме громкой связи. Наличие микрофона и этой функции
в исходном H30 не установлено. Нельзя домысливать ни их наличие, ни отсутствие.
На момент проверки основной URL «Әділет» периодически возвращал timeout;
текст доступен в индексированной публикации того же государственного ресурса.

Таким образом, 8518220009 обоснован для обычной колонки с двумя динамиками
в общем корпусе без дополнительных функций, меняющих классификацию.
Безусловно назначать его текущему неполному описанию нельзя. Автоматически
менять его на 8518309500 тоже нельзя. Нужна спецификация или ответ автора кейса.

Источник структуры веток: [официальная группа 85, страница PDF 33](https://eec.eaeunion.org/comission/department/catr/ett/ru.2022/ru.85_2022_05.07.2026.pdf).

## Как фиксировать окончательные эталоны

Для принятия замены нужны исходное описание, версия номенклатуры, полный путь
условий кода, факты товара для каждого существенного условия и проверка
применимых специальных решений. Число согласившихся ИИ не является доказательством.
Гипотетическая редкая комплектация без нормативного основания также не должна
сама по себе становиться причиной объявлять эталон ошибочным.

Исторический v32_reviewed89 и результаты оставлены неизменными для аудита.
Его нельзя считать окончательно подтверждённым набором: H30 требует уточнения.
Следующий набор следует выпускать отдельной версией после разрешения вопросов,
сохраняя историю изменений и не оптимизируя метки под ответы классификатора.
